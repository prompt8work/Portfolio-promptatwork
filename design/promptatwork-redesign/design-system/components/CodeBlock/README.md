# CodeBlock

A code snippet set in JetBrains Mono on `surface-container-lowest`, with syntax accents taken from the role colours.

- Markup: `<pre class="paw-code">`. Wrap tokens in `.k` (keyword, `secondary`), `.s` (string, `tertiary`), `.f` (function, `primary`) and `.c` (comment, `text-secondary`).
- Use it in course pages and notes. Never use it as decoration in marketing sections.
