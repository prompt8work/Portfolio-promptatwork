# Tag

A pill-shaped, uppercase JetBrains Mono tag that names the tech stack on a course or portfolio card.

- `paw-tag` (blue, the default) · `paw-tag--violet` · `paw-tag--warm` (use once per card at most) · `paw-tag--neutral` (levels, durations).
- Wrap groups in `paw-tags`, which applies a `space-sm` gap.
- Text is the tool's own name, in caps: LANGCHAIN, N8N, GENERATIVE AI. Use 3 or fewer per card.
- Tags are labels, not buttons. For filtering, use FilterChip.
