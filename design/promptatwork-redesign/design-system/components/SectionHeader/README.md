# SectionHeader

A left-aligned section title in `headline-md`, with an optional mono eyebrow above it and a "View all" link on the right.

- Markup: `<div class="paw-section-head"><div><p class="paw-section-head__eyebrow">Courses</p><h2>Latest Frameworks</h2></div><a class="paw-section-head__link">View all →</a></div>`.
- Write titles in Title Case and keep them to two or three words: "Latest Frameworks", "Downloadable Notes", "Selected Work".
- The eyebrow names the content type in caps (COURSES, RESOURCES, PORTFOLIO).
