# NoteCard

A compact row for a downloadable handbook or set of notes: a warm file icon, the title, mono file facts, and a secondary download button.

- Markup: `<div class="paw-note">` → `.paw-note__icon` → a title and a `.paw-note__meta` line → `.paw-btn.paw-btn--secondary.paw-btn--sm`.
- The meta line reads FORMAT · PAGES · SIZE, in caps.
- `tertiary` (the warm note) marks downloadables only. Don't reuse it for courses.
