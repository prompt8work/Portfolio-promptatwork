# Avatar

A circular profile image for the channel avatar on video cards and the profile button in the nav.

- Markup: `<img class="paw-avatar" src="…" alt="Niharika Dhande">`, 36px by default (`paw-avatar--sm` is 32px).
- `paw-avatar--ring` adds the violet ring used for the signed-in user in the top nav.
- When there's no photo, use a `<span class="paw-avatar">` with the person's initials.
- The channel photo is `assets/Photos/niharika-headshot.jpg`.
